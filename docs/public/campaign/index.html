01 — Write once 01 — 一次编写

One tree.
Four screens. 同一棵树。
四块屏幕。

Change the title or the color. Every screen follows. Lynx maps one element tree onto native views — or a custom renderer when you want the pixels to match on desktop too. 改标题或颜色，四端一起变。Lynx 把同一棵元素树映射成各端原生视图；若要桌面端像素一致，也可以走自绘渲染器。

02 — Two threads 02 — 双线程

The tap
doesn't wait. 这一下，
不用等。

The main thread handles the gesture immediately. The background thread commits state afterward, so the first frame does not have to start from a blank screen. 主线程立刻接住手势，后台线程随后提交状态。首帧不必从白屏开始。
